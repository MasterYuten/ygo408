# **游戏王比赛瑞士轮计分习惯**

一般而言，根据每个match的最后结果计算大分。
胜利3分，轮空3分，平局1分，失败0分。
且一般**只计match胜负**，不计具体**小局情况**，一般更无视胜负原因，或者通过难以手工计算复现的“**黑箱小分（胜利小局数等数值）**”进行辅助判定。
本人基于多次举办汉诺杯等比赛的实践，结合“**多劳多得**”“**让实力胜者更有含金量**”等理念初衷，以及较早即微调过的**轮空2分**规则为基础，提出更具体的本细化方法。

# **新细化规则**

为体现实力取胜玩家的含金量，新细化规则的计分方式如下。
胜利3分，**轮空2分**，平局1分，失败0分，依然根据match胜负进行计算。
迟到杀、缺席杀、双败均**无未进行的单局小分**（即**打过的单局小分还是会如实记录、不计入单局小分的部分只影响match胜负判定**）。
具体可参考[汉诺杯共通规定]()。
部分在发表本文时**未明文规定**的胜负原因，如死三杀（“死亡三回合”加时规则中决出胜负）、即死杀（“死亡三回合”加时规则变体，或“即时死亡制”加时规则中决出胜负）等将正常计算单局小分，而掉线杀、犯规杀只影响match胜负判定不计入单局小分，本人将在下个版本更新到《汉诺杯共通规定》。

# **配套计分系统及权重简析**

工欲善其事，必先利其器。现有的游戏王及其他瑞士轮排表系统，未必。
而Challonge（https://challonge.com/）系统的细化自定义功能，则能在配合这个新细化规则作出单局小分区分之余，向所有参赛者**公开原始数据和计算结果，经得起手动计算验证**。
Challonge的默认计分板包含以下项目，权重依次递减。项目后是Challonge自身的说明。

1. **总分**
   人话：其实就是根据match胜负计算的**大分**。
2. **小分：与同分对手相比，获胜的局数**
   人话：某人打赢了**同大分**的其他参赛者多少个**match**。
3. **分数：得分总计**
   人话：由于一般不按小局结果将分数加入大分，因此在这指**胜利小局数**。
4. **Buchholz：Median-Buchholz系统用于在瑞士制中打破平局。排位表中显示的数值代表对手的得分总和（不含最高分和最低**
   **分）**
   人话：去头去尾后，某人所有对手的**大分总和**，俗称**对手分**。
5. **输赢差：总得分和总丢分的差**
   人话：由于一般不按小局结果将分数加入大分，因此在这指**胜利小局数-失败小局数**，会出现负数。此处简称**净胜利小局数**。

# **新细化规则体系**

显然，新细化规则会影响Challonge计分系统的是3（分数）、5（输赢差）两项。1（总分）、2（小分）、4（Buchholz）只与match数、大分有关，不受影响。
根据match赛况不同，参赛者得分会有以下梯度式变化。2、4两项与其他参赛者相关，过于复杂，且非重点，因而未列出。

|    赛况    | 1. 总分（大分） | 3. 分数（胜利小局数） | 5. 输赢差（胜利小局数-失败小局数） |
| :--------: | :-------------: | :-------------------: | :--------------------------------: |
|  2:0胜利   |       +3        |          +2           |                 +2                 |
|  2:1胜利   |       +3        |          +2           |                 +1                 |
| 对方缺席杀 |       +3        |           0           |                 0                  |
|    轮空    |       +2        |           0           |                 0                  |
|    平局    |       +1        |         0/+1          |                 0                  |
|  0:2失败   |        0        |           0           |                 -2                 |
|  1:2失败   |        0        |          +1           |                 -1                 |

“对方缺席杀”一项的**总分**与胜利相等，比平局、失败都高，各位读者应该没有意见。存在些许争议的是其**分数**为0。

结合上述表格，各位读者可以看出，本人设计该细化规则的想法很简单：努力去打了、赢了，就记入分数，没打、没打赢的自然不记入。

很明显看出，收益最大的赛况是“2:0胜利”，其次是“2:1胜利”。这两个都是该轮胜利参赛者**通过自己的汗水打下的成绩**，如实记录，实至名归。

轮空则是因**参赛人数奇数**，有一名参赛者无法匹配到对手而不得不设置的**结构性**赛况——设置其“未战先败”或“未战先和”均不合适，设置为本轮其他有决斗的参赛者的总分平均数又过于**复杂**。现设置为**仅次于胜利**的总分，可以安抚被轮空的参赛者。

“对方缺席杀”收益设计为介于“轮空”与“2:1胜利”之间——因为其需要付出**等待成本**，且需要冒着对方归来、时间减少但比赛继续的风险，但比起实力胜利属于“**躺赢**”，不适宜与任一实力胜利的收益相同，**降低实力胜利的含金量**。

同时，因为“对方缺席杀”**确实没决斗**，0的分数，也符合整个逻辑体系。

另外，死三杀、即死杀正常计算单局小分亦有其逻辑：迟到杀、规则杀是**可选**的，参赛者可以选择“原谅”继续比赛，通过实力取胜，而非直接“乐得清闲”。而死三杀、即死杀是比赛轮次时间不足，参赛者根本**没有拒绝适用的权利**。此时正常计算单局小分，亦是对参赛者的补偿。

# **竞技向变体规则**

参照竞技向比赛**优先比较大分、体现参赛者含金量**的价值观，在默认规则的基础上，本人提供2个变体规则解决方案。

1. 删除3（分数）一项，只保留5（输赢差），此时记录小局的意义在于用净胜利小局数作最后的破平。即Challonge计分板剩余的项目为“总分、小分、Buchholz、输赢差”。
2. 保留Challonge默认计分板，但在第一阶段的瑞士轮、循环赛出线前，人工确认总分、小分相同的出线边缘的参赛者，手动操作Buchholz数值更高的参赛者优先出线。

以上方案是基于Challonge系统中**分数权重必定大于Buchholz**的默认强制设定所作的**妥协**操作。比赛主办读者姥爷可据此制定娱乐赛、竞技赛的权重标准。

# **拓展阅读——胜利小局数（分数）不是“无用”，而是“引导”**

有人质疑：默认计分板将**分数排在Buchholz之前**，是否不合理？其实，这背后有设计意图——抑制“规则杀”。
本人能推测到Challonge网站主的设计初衷：在一些**迟到杀、缺席杀**赛况中，分数会受影响。没打过的小局不会计算分数，也就是此时分数+0。尤其在退赛造成的缺席杀中，更是系统默认设置另一方match胜利但获胜双方分数+0，如果将分数后置，将会产生“**有规则就用到尽**”的情况——**能用规则将对方迟到杀、缺席杀，就绝不“原谅”对方继续打**。毕竟分数后置甚至删除，意味着**对自己的排名微不足道甚至没有**，是个**合格的理性人**都知道怎么选。

在竞技赛中，再**功利**也无可厚非，尤其是**高奖励**竞技赛，谁不是冲着**奖励**或**荣誉**而来？哪怕是所谓享受决斗的快乐，也只是**高名次玩家的自谦词**。如果由出不了轮且成绩较差的玩家嘴里说出，很可能会被一些围观网友当作“输不起的借口”。

但在娱乐赛中，会显得**鼓励冷血、缺乏人情味，功利导向**，体验还不如直接搞竞技赛——参赛者参加低奖励的娱乐赛，尤其是一些可能只此一次、失不再来的变体规则娱乐赛，就是为了**玩个爽**的，此时比赛更多是一种**鼓励玩家享受变体规则（如有）的形式**，且玩家之间是**社群老面孔**居多（奖励不足，吸引的外来竞技玩家较少）。此时再把允许对方继续比赛这种**道德宽容**转为**吃亏决策**，鼓励参赛者主动采用规则杀胜利而非实力完赛，将会伤害社群老面孔参赛者之间的情感、关系。

把分数权重前置，选择迟到杀、缺席杀就要承担**损失分数的风险**，相当于一种**奖励人性中温和良善**的手段——与其眼里只有胜利而功利适用规则杀，不如好好完赛，按实力分胜负，争取用自己的努力**同时取得总分与分数**。
据此，本人才作出分别制定竞技赛和娱乐赛的标准、并公开两种比赛类型默认的权重的建议。主办方可以主动在比赛公告中告知比赛类型，相当于提前告知参赛者规则及价值取向。

胜利小局数不是无用，而是看主办方用在哪里。
